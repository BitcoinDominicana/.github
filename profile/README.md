Bitcoin Dominicana is an open community initiative working on Bitcoin
knowledge and practical adoption across the Dominican Republic, with
individuals, communities, merchants and educators.

https://bitcoindominicana.com

## Areas

```
[ 01 ]  COMMUNITY
        Meetups / merchants / local activities

[ 02 ]  BITCOIN EDUCATION
        Workshops / wallets / Lightning / training

[ 03 ]  BITCOIN TOURISM
        Travel / merchants / experiences / visitors

[ 04 ]  PLAN PAÍS
        Research / proposals / Dominican Republic

[ 05 ]  KNOWLEDGE CENTER
        Data / documentation / sources / archive
```

International collaboration runs across 01, 02 and 03 rather than forming an
area of its own.

## Public archive

```
PUBLIC ARCHIVE
──────────────────────────────────────────────────────────────

/history        project history + sources
/media          press / interviews / podcasts
/data           open adoption data
/education      educational resources
/research       research + proposals
/tools          open-source tools

─────────────────────────────────────────────────────────────
```

Repositories follow this structure rather than mirroring the five areas, so
one event or dataset can document several at once. They are built from
verifiable sources and separate documented fact from analysis.

Bitcoin Dominicana es una iniciativa comunitaria abierta que trabaja el
conocimiento y la adopción práctica de Bitcoin en la República Dominicana,
con personas, comunidades, comercios y educadores.

https://bitcoindominicana.com

## Áreas

```
[ 01 ]  COMUNIDAD
        Meetups / comercios / actividades locales

[ 02 ]  EDUCACIÓN BITCOIN
        Talleres / wallets / Lightning / formación

[ 03 ]  TURISMO BITCOIN
        Viajes / comercios / experiencias / visitantes

[ 04 ]  PLAN PAÍS
        Investigación / propuestas / República Dominicana

[ 05 ]  CENTRO DE CONOCIMIENTO
        Datos / documentación / fuentes / archivo
```

La colaboración internacional es transversal a 01, 02 y 03, no un área
aparte.

## Archivo público

```
ARCHIVO PÚBLICO
──────────────────────────────────────────────────────────────

/history        historia del proyecto + fuentes
/media          prensa / entrevistas / podcasts
/data           datos abiertos de adopción
/education      recursos educativos
/research       investigación + propuestas
/tools          herramientas de código abierto

──────────────────────────────────────────────────────────────
```

Los repositorios siguen esta estructura en lugar de reproducir las cinco
áreas, de modo que un mismo evento o conjunto de datos pueda documentar
varias a la vez. Se construyen a partir de fuentes verificables y separan el
hecho documentado del análisis.
